Spesifikasi Formal FSM (5-Tuple & Tabel Transisi δ)

▼

Definisi Formal 5-Tuple: M = (Q, Σ, δ, q₀, F)

Q (Himpunan State): {q₀, q₁, q₂, q₃, q_acc, q_rej}
Σ (Alfabet Input): {A-Z, 0-9, Simbol, Spasi}
q₀ (Initial State): q₀ (Idle)
F (Accepting State): {q_acc}
δ (Fungsi Transisi): Q × Σ → Q

Tabel Transisi State (δ)

Current State (q) Kondisi / Input (σ) Next State δ(q, σ) Output / Aksi
q₀ (Idle) Start execution q₁ (Read) Inisialisasi tape & head pembaca
q₁ (Read) Simbol karakter valid q₂ (Lookup) Baca simbol aktif pada tape input
q₁ (Read) Spasi / Delimiter kata q₃ (Output) Cetak pemisah kata (/ atau spasi)
q₂ (Lookup) Simbol terdaftar di kamus q₃ (Output) Konversi berhasil, siapkan output token
q₂ (Lookup) Simbol tidak dikenal q_rej (Reject) Mesin ditolak, hentikan proses (Error)
q₃ (Output) Masih ada simbol berikutnya q₁ (Read) Cetak hasil ke output, geser head pembaca
q₃ (Output) Akhir input (EOF / ε) q_acc (Accept) String sukses diterima sepenuhnya
